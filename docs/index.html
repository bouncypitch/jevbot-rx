A nurse just texts it.

No kiosk, no app. Jev reads every message in one pass, with three typed questions: intent (delivery, status, cancel, confirm), urgency (routine, urgent, STAT) and destination. The robot replies with an ETA and texts again when it arrives.

How it works

The robot's brain is split in two. Code does everything that must be exact. Jev makes the one judgment call code can't: of these safe paths, which one, right now, given the people around me?

WHERE THE TIME GOES

No text to write

Jev returns a probability over the options it's offered in one pass. An LLM writes thinking tokens and then JSON. By the time its answer lands 2–5 s later, people have moved, so the robot waits or acts on a stale view.

WHERE THE COST GOES

Input-only pricing

Jev charges $0.042 per million input tokens, and output is free. LLMs pay for input, output and hidden reasoning tokens on every call.

WHY IT'S SAFE

Code owns safety

Collision prediction, filtering, validation and the safety brake are deterministic and identical for both brains. The model only picks among paths already checked.

Planner: JevPilot's sampling-based local planner (similar to the Dynamic Window Approach) plus a shortest-path route over the corridor graph. Every question sent to Jev: jev-questions.md · Architecture PDF
